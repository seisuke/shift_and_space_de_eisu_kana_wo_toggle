# Homebrew tap

This directory is the source for the project's Homebrew tap. Publish it as
`seisuke/homebrew-shift-and-space-de-eisu-kana-wo-toggle`, then install the
latest source build with:

```sh
brew tap seisuke/shift-and-space-de-eisu-kana-wo-toggle
brew install --HEAD shift-and-space-de-eisu-kana-wo-toggle
```

The formula installs the `.app` under the Homebrew prefix. Its caveats print
the exact command used to launch it.
